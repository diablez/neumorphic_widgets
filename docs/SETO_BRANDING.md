# SETO — visual identity

SETO is the creator identity associated with **engineering, robotics, and software** projects, including the ongoing maintenance of Neumorphic Widgets.

## Visual language

Keep the identity calm, technical, and minimal: a distinct geometric mark, generous negative space, and restrained instrumentation. Use micrographic annotations only when they communicate a relationship or purpose.

| Token | Hex | Use |
| --- | --- | --- |
| Porcelain | `#F7F7F3` | Main background and light-space geometry |
| Graphite | `#303734` | Primary mark, main wordmark and high-contrast text |
| Sage | `#739887` | Dashed orbital guides, registration marks, and secondary typography |
| Grid | `#CAD7CF` | Low-contrast construction guides |
| Copper | `#C29F7D` | Rare optional accents, not a primary logo colour |

**Typography:** Space Mono for the wordmark and small technical labels. Use measured tracking and test legibility at target output sizes. Avoid adding unnecessary typefaces to the primary identity.

**Graphic:** Preserve the approved graphite-and-porcelain continuous curved emblem and its proportions. A single sparse sage dashed orbital circle is preferred over densely layered decorative rings. Keep guide geometry separate from the primary mark so a clean logo variant remains possible.

**Composition reference:** A 1597 × 1597 study canvas with an approximately 987 × 987 upper graphic field and a separate title area. These are design-study parameters, not mandatory dimensions for every output.

## Use in this repository

- Keep the **Neumorphic Widgets** project name and existing Dart package identity. SETO is the creator identity, not a package rename.
- Use this style for repository headers, documentation visuals, and future gallery branding where appropriate.
- Preserve the approved original artwork. Do not treat approximate bitmap tracings or image-generated reinterpretations as mathematically exact source vectors.
- For small surfaces, prioritise a readable emblem and wordmark over decorative measurements.
